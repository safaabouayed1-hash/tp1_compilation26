## Exercises

1. **Calculatrice** — two integers + operator (A/S/M/D) → result
2. **Échange** — swap two integers using pointers
3. **Plus grande valeur** — find the largest value in an array
4. **Affiche chaîne** — print a string with a space between each character
5. **Voyelles** — count the vowels in a string
6. **Login / Mot de passe** — validate login and password (5 rules)
